# Design studies

Static, self-contained HTML studies made while shaping Meteor's visual identity. Open them in a browser. They make no network requests, and all infrastructure names and numbers in them are fictional.

| File | What it explores |
| --- | --- |
| [`appearance-study.html`](appearance-study.html) | Light, dark and system modes with the four accent colours used by the app. |
| [`orbit-study.html`](orbit-study.html) | The pool → host → VM hierarchy, per-VM custom icons and taglines. |
| [`icon-hybrid-study.html`](icon-hybrid-study.html) | The silver "hybrid" meteor mark at launcher, header and splash sizes. |

The meteor artwork in `assets/` (the hybrid mark, also used in the app, and the natural and wireframe variants it is compared with) was produced with an AI image model and keeps its original C2PA content credentials.

Some studies show controls for capabilities that are still on the roadmap (such as multiple pools or Xen Orchestra). The app's current scope is described in the main [README](../README.md).
