# License: not yet chosen

This repository does not have a license yet. Until one is added, the default applies: all rights are reserved, and the code may be viewed but not reused, modified or redistributed.

Before publishing, pick a license, add it as `LICENSE` at the repository root, update the "License" section of `README.md`, and delete this file.

Common choices for a portfolio project:

- **MIT** or **Apache-2.0**: permissive. Apache-2.0 adds an explicit patent grant.
- **GPL-3.0**: copyleft. Derivative apps must also be open source.
- **No license**: keeps all rights reserved and signals "look, don't reuse".

Note: the design artwork in `design/assets/` may need its own terms if it should not be reused under the code license.
